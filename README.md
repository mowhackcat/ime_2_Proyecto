Que se espera al correrlo
El programa le pedirá al usuario que ingrese la siguiente informacion:

1.-Pregunte por la cantidad de miembros en un equipo
2.-Pregunte por el nombre y la carrera de cada participante 
3.-Pregunte por la cantidad de robots, su nombre y tipo

Si las condiciones se cumplen, que inicie una batalla entre dos robots del mismo tipo y ques escoga a un ganador de manera al azar
